---
description: Generate or refresh the per-(code-repo, branch) session brief.
---

The session brief is a short digest of decisions, in-flight files, and recent project activity from the CE workspace. It lives at `<code-repo>/.curiosity/session-brief.md` (per-machine, gitignored) and is auto-generated by the agent at session start when `[brief] auto = true` in the pointer file.

Use `/brief` to regenerate on demand — for example, after switching branches, after a `git pull`, or whenever the in-flight file set has changed materially.

**Workspace context.** Apply the workspace-resolution rule from SKILL.md § Code-repo mode. This command requires code-repo mode (cwd has `.curiosity/config.toml`); refuse otherwise with: "no pointer file here — `/brief` only runs in a registered code repo. See `docs/code-knowledge.md`."

**Action.** Run:

```bash
uv run python3 <skill_path>/scripts/session_brief.py --quiet
```

Then read the generated brief and summarise its key sections back to the user (in-flight files, recent decisions, anything notable). The full brief stays in `.curiosity/session-brief.md` for the next agent session to pick up.

If the brief is empty (no project-tagged content in the workspace yet), tell the user: "the workspace has nothing tagged with this project yet. As captures accumulate (PR merges, agent sessions, /distill outputs), the brief will fill in."
